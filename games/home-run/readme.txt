Wilds avec multiplicateurs (2x à 100x)
Les multis des wilds d'une même ligne se MULTIPLIENT entre eux
  ex. ×2 et ×3 sur la ligne → ×6

Basegame :
- Scatter sur tous les rouleaux
- Wilds peuvent avoir un multi (surtout ×2 / ×3)
- 3 scatters = 10 FS, 4 = 12, 5 = 15

FreeGame :
- Plus de wilds / multis plus élevés
- ×2 × ×2 × ×5 = ×20 sur une ligne gagnante
